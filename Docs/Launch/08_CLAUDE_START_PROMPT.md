## Ограничения M0

- Не создавать и не менять исходники, сцены, ассеты, .meta, Packages, ProjectSettings, сохранения или Git-состояние старого проекта.
- Не выполнять reset --hard, clean, checkout/restore поверх изменений, массовое удаление, перенос или переименование. Не выполнять git add/commit/push в старой папке.
- Не запускать в старом проекте Unity, пакетные менеджеры, restore, импорт, сборку, тесты, генераторы, hooks и неизвестные скрипты. Даже «проверка» может создавать Library и менять файлы.
- Не менять глобальный Git config и safe.directory. Если Git отказывает из-за ownership, запиши ограничение; не обходи его массовым доверием ко всем папкам. `git status` в репозитории с LFS может запускать фильтры: не используй его без оценки побочных эффектов. Чистота старого репозитория не нужна для создания отдельной новой игры.
- Не читать бинарные графические файлы и не загружать ассеты ради аудита.
- Не создавать новый проект в этом первом запросе. Не запускать установку/обновление Unity или зависимостей.
- Не делать вывод «всё работает» по наличию файлов. Разделяй: прочитано, написано, скомпилировано, EditMode, PlayMode, APK собран, APK запущен на телефоне.
