# ServerClosed — пакет запуска НОВОЙ игры

Версия 1.0 · 23 октября 2026 · язык работы: русский.

## Главная поправка автора

Это **новая игра и отдельный новый Unity-проект**, а не продолжение найденной реализации. Автор выбрал: «Отдельный проект рядом; старую папку сохранить». Старые исходники, сюжет, персонажи, механики и GDD не являются требованиями новой игры и не переносятся автоматически.

| Назначение | Путь / статус |
|---|---|
| Старый проект, только для ограниченного аудита | `C:\UnityProjects\ServerClosed\Game` |
| Корень старого репозитория | `C:\UnityProjects\ServerClosed` |
| Предлагаемый корень нового проекта | `C:\UnityProjects\ServerClosed_New` |
| Предлагаемый Unity-проект | `C:\UnityProjects\ServerClosed_New\Game` |
| Документы после начала реализации | `C:\UnityProjects\ServerClosed_New\Docs\Launch` |

Предлагаемая новая папка при проверке отсутствовала. Она **не создана** этим пакетом. Claude должен повторно проверить путь перед созданием. Если он занят — не очищать и не перезаписывать; предложить свободный соседний путь. Новый репозиторий не должен находиться внутри старого.

## Что уже решено, а что предложено

**Подтверждено автором:** новая игра; отдельный проект; старые файлы сохранить; Unity 6.6; Android; несколько связанных регионов с единым временем; постепенное старение с растущей вероятностью смерти; проработка кармы, души, реинкарнации, генов, RPG, Magic Chess и живого мира; работа через Claude Desktop Code с Gateway.

**Проектное предложение этого пакета:** одиночная офлайн-игра, остановка мира при закрытии приложения, календарь 120 дней, тактические бои с автоматическим исполнением приказов, ограниченное наследие души, три стартовых региона и конкретные числа баланса. Это согласованная между документами рабочая спецификация для прототипа, а не утверждение, что автор ранее утвердил каждое число.

**Не подтверждено:** окончательный сюжет и название; наличие Unity 6.6 в новой среде Claude; конкретный телефон; провайдер Gateway; коммерческие требования; успешная сборка старого или нового проекта.

## Как начать

1. Откройте Claude Desktop, вкладку Code, с уже настроенным Gateway. Не вставляйте ключи в чат или файлы проекта.
2. Дайте Claude доступ к этому пакету и к старой папке для чтения. Если он видит только выбранную рабочую папку, приложите документы отдельно; не копируйте их поверх старого проекта.
3. Скопируйте весь текст задания из `08_CLAUDE_START_PROMPT.md`. Это запускает аудит, а не создание/перезапись игры.
4. Получите отчёт с путями, ограничениями доступа, конфликтами и планом первого этапа. Отсутствие доступа — причина отметить «не проверено», а не сочинять содержимое файлов.
5. После проверки отчёта отправьте: «Начинай этап M1 в отдельном новом проекте по пакету. Старый проект не изменяй. Затем выполни проверки M1 и остановись с отчётом». Настоящие требования при этом важнее черновых чисел.

## Контракт результата

Пакет — документация и задания, **не готовый Unity-проект**. В этом сеансе выполнено ограниченное чтение старых файлов и внешней документации. Unity не запускался, EditMode/PlayMode-тесты не исполнялись, APK не собирался, телефон не проверялся. Наличие старых файлов не доказывает работоспособность новой игры.

При расхождении документов: уточнение автора → таблица решений в документе 09 → правила систем 02–04 → техническая реализация 05 → числа старых файлов. Последние служат только исторической справкой и не обладают силой требования.
