# SERVERCLOSED — исправленный Unity-порт v1.1

Проект: `C:\UnityProjects\ServerClosed_New\Game1`, Unity **6000.6.5f1**.
Сцена игры: `Assets/Scenes/ServerClosed.unity`.

## Запуск

Откройте Game1 в Unity, дождитесь компиляции, откройте указанную сцену и нажмите Play.
Клавиатура: WASD/стрелки — движение в направлениях экрана, Shift — спринт,
Space — атака, E — поглощение или выход из норки у лаза.
Мышь: щелчок по земле задаёт цель движения. На телефоне: тап или перетаскивание.
Кнопки интерфейса не должны задавать герою цель движения.

Норка открывается после усвоения 8 биомассы либо развития двух дополнительных чувств.
Сначала атакуйте мелкое существо, затем поглотите труп и дождитесь переваривания.

## Исправления

- Ошибки компиляции исходного архива: пространства имён, коллекции, количество руды, float/double.
- Поддержка установленного нового Input System без переключения проекта на старый ввод.
- Движение клавиатурой и джойстиком преобразуется в изометрические координаты; спринт действительно ускоряет тело.
- Интерфейс масштабируется по высоте экрана для телефонов.
- Клавиши E/Space работают; щелчки по панелям и кнопкам не двигают игрока.
- Отсутствующие множители порогов чувств означают 1, а не 0: первая еда больше не открывает все органы.
- Зрение расширяет разведку карты; далёкие незамеченные существа скрыты туманом.
- Пауза, нечисловой/отрицательный шаг времени и команды мёртвому телу не изменяют симуляцию.
- Генератор случайности и счётчик дней продолжаются после загрузки.
- Перерождение заменяет тело в существующем мире; карта, время и надземная популяция сохраняются.
- Вложенные списки разведки подземелий сохраняются; повреждённый JSON отклоняется.
- Два слота сохранения с версией, последовательностью и SHA-256; сначала проверяется временный файл, затем атомарно заменяется более старый слот.
- Ошибка загрузки не начинает новую кампанию; старый файл прототипа не перезаписывается при миграции.
- Платформенное хранение отделено от чистого Core; отдельная сборка Core запрещает ссылки на Unity.
- Добавлен собственный шейдер процедурной геометрии в Resources и защита моделей от удаления IL2CPP.
- Освобождаются созданные меши и материалы; камера сразу расположена у героя.
- Android: минимум API 26, целевой API 36, ARM64/IL2CPP, альбомная ориентация, отдельный пакет `com.serverclosed.newgame`.

## Сохранения

`Application.persistentDataPath/ServerClosedPort/sc_save_0.json` и `sc_save_1.json`.
При повреждении нового слота загружается предыдущий исправный. Два повреждённых слота
дают сообщение об ошибке; данные остаются на диске для восстановления.
Оригинальный `sc_save.json` поддержан как источник миграции.
Веб-сохранения localStorage напрямую в Unity не импортируются.

## Проверки

19 регрессионных сценариев доступны через Unity Test Runner (EditMode, `ServerClosed.Port.Tests`).
Отчёты конкретной сборки, журналы и результат проверки устройства — в `VALIDATION.md`.
Тестовый режим Windows: `ServerClosed.exe --sc-smoke <папка-отчётов>`.
Он использует отдельное сохранение и автоматически завершает игру.

## Пределы переноса

Это исправленный вертикальный срез v1, а не перенос всех возможностей веб-версии.
Шахматы суда души, NPC/диалоги/задания, полная экономика поселения, сезоны с эффектами,
прочие подземелья и спрайтовая графика остаются следующими этапами.
Правила большого проекта (например, его отдельный календарь) требуют дальнейшего
согласования с прототипом; существующее ядро `_Project` не заменялось.
