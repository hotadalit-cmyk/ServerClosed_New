# ServerClosed New

Новая одиночная 2D RPG для Android на Unity 6.6.

- Несколько связанных регионов с единым временем
- Постепенное старение, смерть, реинкарнация
- Карма, душа, гены, RPG, тактический бой
- Живой мир, история продолжается между жизнями

Документация: `Docs/Launch/`
Правила разработки: `CLAUDE.md`

Старый проект `C:\UnityProjects\ServerClosed` — отдельная игра, не переносится.
