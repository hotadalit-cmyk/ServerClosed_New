# SERVERCLOSED — Unity-проект

Проверенный C#-порт вертикального среза игры «Две жизни одного слизня».
Текущая версия переноса: **v1.1**, проверена 24 октября 2026 года.

## Начало работы

1. Клонируйте этот репозиторий.
2. В Unity Hub откройте **папку `Game1`**, а не корень репозитория.
3. Используйте **Unity 6000.6.5f1**; пакеты зафиксированы в `Game1/Packages`.
4. Дождитесь импорта и компиляции.
5. Откройте `Game1/Assets/Scenes/ServerClosed.unity` и нажмите Play.

Главный код: [`Game1/Assets/ServerClosed`](Game1/Assets/ServerClosed).
Для продолжения работы другим ИИ начните с **[инструкции передачи проекта](Docs/AI_HANDOFF.md)**.

## Что работает

Родовая норка и выход в большой мир, движение и бой, поглощение и пищеварение,
развитие органов чувств и генома, туман войны, процедурный слизень,
старение, карма, перерождение тела в сохраняющемся мире, двухслотовые сохранения.

Управление: WASD/стрелки, Shift — спринт, Space — атака, E — поглощение/выход.
На телефоне: тап по земле или перетаскивание, кнопки действий.

## Проверка и сборка

Откройте Window → General → Test Runner → EditMode и выполните `ServerClosed.Port.Tests`.
Последний результат: **19/19 PASS**.

В автоматическом режиме из корня репозитория:

```powershell
& '<путь к Unity.exe>' -batchmode -nographics -projectPath "$PWD/Game1" -runTests -testPlatform EditMode -testFilter ServerClosed.Port.Tests -testResults "$PWD/editmode-results.xml" -logFile "$PWD/editmode.log"
```

Для создания APK используйте `-executeMethod ServerClosed.Validation.ScBuildValidation.BuildAndroid`
вместо параметров Test Runner и добавьте `-quit`. Для Windows — `BuildWindows`.
Переменная окружения `SC_VALIDATION_OUT` задаёт папку результата; по умолчанию это
`Game1/Builds/ServerClosed`.

Android: ARM64, IL2CPP, минимум API 26, целевой API 36, альбомная ориентация,
идентификатор `com.serverclosed.newgame`. Скрипт создаёт **проверочную Development-сборку**
с тестовой подписью; это не публикация в магазине.
