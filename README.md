# ServerClosed — новая игра

Одиночная 2D RPG для Android. Unity 6.6, портрет, тактический бой.

Концепция: несколько жизней в одном меняющемся мире. Старение, карма, реинкарнация, гены, живой мир.

## Структура

- `Game/` — Unity-проект 6000.6.5f1
- `Docs/Launch/` — пакет требований
- `Artifacts/` — сборки APK (не в Git)
