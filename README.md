# SERVERCLOSED — Unity-проект

Проверенный C#-порт игры «Две жизни одного слизня» по веб-прототипу v2.
Текущая версия: **v1.3 с проверенной интеграцией Unity**.
Независимая проверка: **56/56 EditMode PASS**, Windows и Android собраны,
сценарий «Дар → оборона → Катакомбы → Суд → новое тело» выполнен в плеере и на телефоне.
[Отчёт и ограничения](Docs/Validation/2026-10-24-unity-v1.3-verified.md).

## Начало работы

1. Клонируйте этот репозиторий.
2. В Unity Hub откройте **папку `Game1`**, а не корень репозитория.
3. Используйте **Unity 6000.6.5f1**; пакеты зафиксированы в `Game1/Packages`.
4. Дождитесь импорта и компиляции.
5. Откройте `Game1/Assets/Scenes/ServerClosed.unity` и нажмите Play.

Главный код: [`Game1/Assets/ServerClosed`](Game1/Assets/ServerClosed).
Для продолжения работы другим ИИ начните с **[инструкции передачи проекта](Docs/AI_HANDOFF.md)**.

## Что работает

Полный цикл жизни: родовая норка → большой мир → смерть → Суд души →
выбор тела → новое воплощение в живом мире.

- **Тело**: поглощение, две полости пищеварения, диета, 7 органов чувств, геном,
  синергии, узлы эволюции, старение и мутации.
- **Мир**: экосистема популяций по сезонам (4×6 дней) с миграциями зверя,
  посёлок Опушка — стадия Хутор→Деревня→Посад, экономика, стража, набеги волков,
  NPC (Мирра/Дар/Клумба и преемники) с диалогами, заданиями (6), пожертвованиями
  и кражей.
- **Magic Chess**: оборона посёлка — ростер из изученных видов, расстановка при
  остановленном времени, автобой, синергии, последствия для посёлка и стаи.
- **Подземелья**: Грибные Катакомбы и Кристальные Пещеры (3 глубины, боссы
  Грибной Монарх и Кристальный Титан с генами-трофеями), Подземное русло,
  приносы, лестницы, разведка этажей.
- **«Чаша Отголосов»**: 18 мировых регионов, открываются только ногами/чутьём;
  тайная трещина для малого тела; родовая норка вне сезонов.
- **Душа**: карма (пути Свет/Равновесие/Тьма с ежедневными эффектами), суд души
  с долями регионов рождения и причинами, черты души от реальных поступков,
  16 достижений, 6 воспоминаний, выбор тела при перерождении, наследие биомассы
  и генов, скачок времени между жизнями.

Управление: WASD/стрелки, Shift — спринт, Space — атака, E — говорить/вход в
подземелье/лестницы/принос/поглощение. На телефоне: тап по земле или
перетаскивание, кнопки действий.

## Проверка и сборка

Откройте Window → General → Test Runner → EditMode и выполните `ServerClosed.Port.Tests`
(56 кейсов: исходные 52 плюс 4 регрессии интеграции).
Результаты .NET и Unity: **56/56 PASS**; свидетельства —
`Docs/Validation/port-v1.3-unity-evidence/`.

В автоматическом режиме из корня репозитория:

```powershell
& '<путь к Unity.exe>' -batchmode -nographics -projectPath "$PWD/Game1" -runTests -testPlatform EditMode -testFilter ServerClosed.Port.Tests -testResults "$PWD/editmode-results.xml" -logFile "$PWD/editmode.log"
```

Для создания APK используйте `-executeMethod ServerClosed.Validation.ScBuildValidation.BuildAndroid`
вместо параметров Test Runner и добавьте `-quit`. Для Windows — `BuildWindows`.
Переменная окружения `SC_VALIDATION_OUT` задаёт папку результата; по умолчанию это
`Game1/Builds/ServerClosed`.

Android: ARM64, IL2CPP, минимум API 26, целевой API 36, альбомная ориентация,
идентификатор `com.serverclosed.newgame`. Скрипт создаёт **проверочную Development-сборку**
с тестовой подписью; это не публикация в магазине.

## Проверенное состояние и ограничения

Windows и Android ARM64/IL2CPP собраны. Сценарий диалога, обороны, трёх этажей
Катакомб, Суда, выбора тела и сохранения выполнен на Windows и Samsung SM-G780F / Android 13.
Исправлены восстановление и детерминизм шахмат, повторные награды, границы доски,
точность JSON под Mono, отрисовка доски и модальных экранов.

Ручные Windows-клики не выполнены: инструмент захвата окна завершился тайм-аутом.
Оставшиеся сообщения AssetPackManager/Bloom, ограничения единого времени в шахматах
и границы покрытия перечислены в [отчёте](Docs/Validation/2026-10-24-unity-v1.3-verified.md).
Полный баланс и пиксельный паритет с вебом не объявляются проверенными.

Для автоматического сценария: Development-плеер с `--sc-review <отдельная-папка> --auto-flow`;
на Android — boolean intent-extra `scFlow=true`. В обычной игре этот режим выключен.

Сгенерированные папки Unity, личные сохранения и бинарные сборки не входят в Git.
