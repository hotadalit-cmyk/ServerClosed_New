# M1.2: Создание Unity-проекта через Hub

## Требуется ручное выполнение

Unity проект нельзя надёжно создать только файлами — нужна инициализация через редактор.

### Шаги:

1. Открыть Unity Hub
2. Нажать "New project"
3. Выбрать:
   - Editor Version: **6000.6.5f1**
   - Template: **2D (URP)** или **2D Core**
   - Project name: **Game**
   - Location: **C:\UnityProjects\ServerClosed_New**
   
4. Нажать "Create project"

5. Дождаться первой компиляции (Library создастся автоматически)

6. Закрыть Unity Editor

7. В чате Claude написать: **"Проект создан"**

### Альтернатива (если Unity Hub недоступен):

Можно продолжить с минимальной структурой, но Android-сборка потребует редактора для настройки Build Profile.
